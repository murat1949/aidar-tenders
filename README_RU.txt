Боевой портал — версия v1.0.4 TEAM ACCESS

Изменено:
- длинный технический код доступа встроен в портал;
- окно технической настройки удалено;
- добавлен простой вход по 4-значному коду;
- предусмотрены роли администратора и сотрудников;
- вход действует в пределах текущего сеанса браузера;
- пользоваться порталом можно с любого компьютера по одной ссылке;
- несколько сотрудников могут работать одновременно.

Коды для тестирования:
1111 — Администратор
2222 — Сотрудник 1
3333 — Сотрудник 2
4444 — Сотрудник 3
5555 — Сотрудник 4

Важно:
- это упрощённая защита для этапа внутреннего тестирования;
- обычным сотрудникам кнопка обновления Samruk скрыта;
- перенос самого механизма обновления Samruk с локального компьютера в интернет — отдельный следующий этап.
